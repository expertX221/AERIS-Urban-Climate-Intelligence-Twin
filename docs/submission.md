# AERIS submission draft

**Track:** ClimateTech & Sustainability.

**Project:** AERIS — Urban Climate Intelligence Twin.

**Problem:** Climate variables and design choices are difficult to connect when presented in separate technical views. AERIS explores a spatial interface that makes those relationships approachable.

**Solution:** A cinematic website introduces a district, then smoothly transfers visitors to original 3D scenes for city form, heat, water and regeneration. A connected explorer lets users inspect objects and compare synthetic intervention scenarios.

**Implementation:** React/Vite UI, persistent Three.js renderer, four original Blender-to-GLB models, scroll-linked camera state, raycast object selection, semantic inspection alternatives, localStorage scenarios, URL-encoded sharing, JSON export and optional Web Audio synthesis. Deployment: Vercel, source: https://github.com/expertX221/AERIS-.

**Originality:** A spatial storytelling and transparent scenario interface integrating presentation and exploration. This is a design/engineering prototype; no claim of a novel validated climate algorithm is made.

**Data and external resources:** Synthetic district and inputs. No personal or real-world sensor datasets. AI-generated cinematic artwork; original procedural Blender models. React, Vite, Three.js, Phosphor and Google Fonts are acknowledged in README.

**Evaluation:** Automated checks verify input bounds, baseline consistency, intervention response direction, asset format, expected scene content and distinct exports. These validate software behavior, not scientific accuracy. Browser evidence and unresolved gaps belong in design-qa.md.

**Three-minute demo:**

1. Open the landing page; explain the problem and simulated-data label.
2. Scroll City → Heat → Water → Regeneration; explain the original Blender scenes.
3. Launch the explorer, select a building, then use the keyboard-accessible park/river shortcuts.
4. Increase canopy, cool roofs and permeability. Show the response and switch to baseline.
5. Save locally, export JSON and copy a share link. Open Method to show equations and limitations.
6. Explain next steps: georeferenced data, calibration, held-out validation, uncertainty and user testing.

**Scope disclosure:** This repository began with only a README. Prototype code, models and artwork were created during this hackathon work with AI assistance. No measured climate result, AI prediction, backend collaboration or live telemetry is claimed.
